# 飞鸽传信 · 云间来信

手机与电脑都能玩的 30 关飞行冒险。三段旅程各有场景、角色、收集目标和飞行能力：江南信鸽送信、山海纸鹤寻风铃、星河萤灯点亮星光。

30 关各有独立的 Canvas 场景配色、地貌与地标，关卡地图展示对应的场景预览。`public/scenery.mjs` 绘制背景，`public/levels.mjs` 定义每关的目标、特色与收集物飞行路线，`public/engine.mjs` 实现物理与碰撞，`public/game.js` 负责渲染与操作。玩法和场景都可以直接改代码；角色 WebP 是独立美术资源。

每关约半分钟，有独立目标和逐步变化的风、危险物、连收奖励与道具。江南篇第 4 关起，影隼会先预告俯冲路线；及时改变高度可以躲过，惊险擦翼还能获得加分。完成目标后逐关解锁；多收集、少受伤可拿到 1 至 3 星。关卡地图可以重玩已解锁关卡，挑战更多星。

每日邮路从已解锁关卡中选一条航线，另设三连收集、平安抵达或双星目标。完成可在邮戳簿留下当日记录，次日出现新任务；通关后可分享或下载旅程卡片。30 个关卡的邮戳与星级构成长期收集目标。

## 操作

- 空格 / ↑ / W：向上飞；快速连按两次空格或按 P：暂停 / 继续。
- R：重玩本关；M：开关声音；H：查看按键与重开练习。
- 手机：轻点画面或「拍翅」按钮，右上角暂停。浏览器第一次互动后启动游戏声音。

## 存档

游客关卡和每日邮路记录保存在当前设备。使用 ChatGPT 登录后，已完成关卡、最高分、最多星级和每日邮戳存入 D1，跨设备同步。游客记录在登录后同步到账号。旧版三段旅程的完成与驿站进度会换算成已通关的新关卡。

站点绑定见 `.openai/hosting.json`，数据库迁移位于 `drizzle/`。`npm run build` 生成 Cloudflare Workers 兼容的站点。

## 在电脑上运行源码

需要 Node.js 22.13 或更高版本。下载仓库后，在项目目录运行：

```bash
npm install
npm run dev
```

游客玩法可在本地体验；ChatGPT 登录与跨设备 D1 存档需要 Sites 部署环境。
